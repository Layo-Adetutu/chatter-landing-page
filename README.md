 # CHATTER – A Haven for Text-Based Content

### AltSchool Africa | AI-Powered FullStack Karatu 2026 – First Semester Project

## About the Project

I built this project as part of my AltSchool Africa AI-Powered FullStack Karatu 2026 First Semester assessment.

The project involved recreating a landing page design provided on Figma using HTML and CSS.
( figma link - https://www.figma.com/design/TXzuoMAwGEIfWcAq0HbBNY/purposed?node-id=52-41&t=wL4yzJ1YDbf8hT7e-0) 

Chatter is a multi-functional blogging and content-sharing platform designed to connect writers and readers. The idea behind the platform is to create a welcoming space where people can publish articles, discover interesting content, share ideas, and interact with like-minded individuals.

My goal was to translate the provided Figma design into a functional, visually appealing, and responsive webpage while maintaining the overall layout and design direction.

## What I Built

The landing page consists of the following sections:

- **Navigation Bar:** Contains the Chatter logo, navigation links, and Login and Sign Up buttons.
- **Hero Section:** Introduces Chatter with a background image, welcome message, short description, and Get Started button.
- **About Chatter:** Provides an overview of the platform, its purpose, and its vision.
- **Why You Should Join Chatter:** Highlights three major platform features: Analytics, Social Interactions, and Content Creation.
- **Testimonial Section:** Showcases a user testimonial to communicate the value of the platform.
- **Community Section:** Encourages visitors to read, write, share ideas, and connect with other members.
- **Footer:** Contains navigation links grouped under Explore, Support, and Official Blog.

## Technologies Used

- HTML5 – For structuring the webpage.
- CSS3 – For styling, layout, responsiveness, and visual presentation.

## Key Features

- Clean and modern user interface.
- Responsive layout for desktop, tablet, and mobile devices.
- Organized page sections.
- Interactive navigation links and call-to-action buttons.
- CSS-based mobile navigation menu.
- Images integrated into their respective sections.
